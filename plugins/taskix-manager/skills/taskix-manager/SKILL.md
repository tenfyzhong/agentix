# Taskix Manager

Before any tracked work, read [the complete Taskix workflow](references/workflow.md).
Follow its routing, ownership, Plan, dependency, review, document, and lifecycle
rules. This reference is mandatory for every host; do not replace it with a
shortened workflow.

Use `taskix --json` or the host's native `taskix` tool. Read the
[command reference](references/commands.md) when creating work or changing state.
